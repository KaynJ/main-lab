# 本命实验室 · MAIN LAB 产品说明

版本：0.4.0（本地更新）。面向希望入门、换位置或尝试新玩法的玩家，用几分钟问卷提供具体、可解释、能试玩检验的建议。当前是玩家推荐工具，尚未建设正式心理实验平台；线上版本以 GitHub Actions 部署结果为准。

## 一次完整体验

1. 选择游戏或输入常见名称，页面切换对应的官方场景。七款游戏均有本地背景，品牌使用用户提供的头像。
2. 填写游戏时长和实际条件，可备注已有 MBTI。英雄联盟询问熟练度、操作投入、目标、组队、位置、玩法、地图关注和距离；三角洲询问模式、平台、距离、打法、操作练习、组队、配装取向、兵种、赛季档案与 MBTI 使用方式。
3. 完成 12 道带图片的偏好题。三角洲有专用题干及官方情境图；图片不参与计分，也不决定推荐的英雄或干员。
4. 英雄联盟生成峡谷排位与海克斯大乱斗两部分报告；三角洲生成兵种、干员、打法和枪械报告，支持烽火地带与全面战场切换；其他五款游戏生成三个基础方向。
5. 查看练习、观摩对象与中国平台入口，下载 Markdown 报告；也可调整实际条件并保留答案。

界面采用黑底白字，背景随游戏选择变化，问卷与报告保持可读性，并尊重系统减少动态效果的偏好。

## 英雄联盟双模式

| 部分 | 当前资料 | 输出 |
| --- | --- | --- |
| 召唤师峡谷 · 排位 | 五位置、20 位英雄 | 位置、首试英雄池、进阶候选、理由与摩擦点、练习、排位准备路线、职业选手与主播 |
| 海克斯大乱斗 | 八位英雄、每人两条流派 | 候选、实际随机英雄筛选、强化属性方向、缺少联动时的备选、风险取舍与教学入口 |

海克斯英雄库包括乌迪尔、墨菲特、布兰德、厄运小姐、艾希、索拉卡、盖伦、拉克丝。乌迪尔区分 AP 觉醒 R 与物理 Q 爆发，其他英雄也提供两种不同体验。英雄随机分配，不能保证拿到推荐候选。选择实际随机英雄后只展示该英雄的路线，切换峡谷位置不改变海克斯排序。

“优先寻找”描述强化属性和机制方向，不伪造具体强化名称，也不承诺当局强化池。路线同时说明没有核心联动时如何转向，以及进场、生存、伤害或团队贡献上的代价。

## 三角洲行动

以烽火地带为第一入口，同时提供全面战场。四种方向为突击、信息（官方侦察兵种）、工程、支援 / 医疗；17 位干员都有机制摘要、适合的体验、取舍、练习和两种模式的打法提示。15 把枪按距离、操控练习和投入匹配，枪械推荐首先回答“愿不愿意用、能不能稳定命中”。

结果先比较兵种，再给同兵种干员和三把试用枪械。手动兵种优先；低、中、高练习投入分别限制首试干员的编辑学习成本，避免低投入直接首推复杂操作。枪械类型不等于当前全面战场的可用性：当期兵种枪池尚未核验，界面提示在客户端确认。

赛季档案收录 ALWAYS聪聪本人 B站的 S9、S10、S11 原视频。只摘要有限的候选和明确变体，不复刻整榜。选 S11 不调用 S10 等级；未知平台不计强度分；特定枪管、套件和弹药也不能套给基础枪。全面战场不用烽火市场预算及梯度。详见 [三角洲规则与维护](delta.md)、[干员来源](delta-operator-sources.md)、[枪械来源](delta-weapon-sources.md)。

三角洲新增 30 张本地官方图：一张航天基地背景、12 张问卷情境图、17 张干员头像。图片源地址、权利归属和核对范围记录于 [图片来源](delta-visual-sources.md)。

## 学习内容

观摩对象分职业选手与主播。前者侧重比赛决策、兵线、资源和团战，后者侧重英雄细节、完整对局和练习思路。每个入口说明对应英雄和“重点看什么”，避免只给人名。

当前 20 位峡谷英雄均有学习入口：11 个固定视频、九个 B站搜索入口。职业、主播、英雄教学和海克斯教学链接使用 B站、抖音等中国平台。搜索页明确标注，固定视频记录发布者和年份；历史出装与数值不作为当前版本答案。公开元数据核对不等于完整观看，也不保证所有用户的播放权限。

三角洲干员教学是明确标注的 B站检索入口，枪械资料链接则指向本人原视频。正式赛季榜、单枪解析、资料收录日期和视频日期分别记录。来源维护可独立于界面扩充。

## 推荐规则

12 道自编题覆盖六维偏好，每维两题，含反向计分。玩法、英雄、位置与流派标签由编辑整理，同一输入产生可复现结果。

MBTI 默认只作备注。三角洲可主动开启轻量参考，单个干员排序最多 ±1.5 分；这是未经预测效果验证的编辑假设，不影响枪械得分、距离筛选或模式资格。英雄联盟和其他五款游戏仍只备注。

峡谷按学习投入筛选，再结合偏好、学习成本、玩法、距离与地图负担。海克斯独立考虑六维偏好、流派、学习成本、距离、组队与目标，不使用峡谷位置分数。界面给出理由与摩擦点，规则分不解释为概率或能力判断。

## 当前边界

- 王者荣耀、无畏契约、最终幻想14、魔兽世界、我的世界仍为基础推荐，尚无逐英雄或职业的独立资料库。
- 问卷与规则尚未经心理测量或推荐效果验证，不预测技术、段位或胜率。
- 没有实时平衡数据、账号资料、排位准入或强化池接口；实际内容以客户端为准。
- 答案在浏览器临时计算，刷新清空；没有账号、云端问卷存储、实验分组或研究数据导出。
- 仓库已有 GitHub Pages 自动部署配置；本地 0.4.0 尚需提交推送，线上状态以 Actions 和 Pages 发布结果为准。

后续优先记录真实试玩后的享受程度、压力、继续尝试意愿，以及建议是否可执行；再据此调整推荐，扩充中文原作者资料与其他游戏数据。正式心理实验功能需另行设计，不能把“用户觉得准”当作科学验证。
