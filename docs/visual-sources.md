## 验证

- 所有 18 张运行图片均检查实际 HTTP Content-Type、Pillow 解码及像素尺寸，未将 HTML 页面保存为图片。
- 全部以本地路径供页面使用；浏览器中的裁切由 CSS 的 `object-fit` / `background-size` 控制。
- HTTPS 下载保留系统证书验证。PowerShell 的连接在本次环境中未通过证书握手，实际下载使用默认验证的 Python `urllib`。
- 临时 HTML、JS、JSON、ZIP 与候选联系表均已移除，静态资源目录仅保留页面需要的图片。

## 本地英雄头像

核对日期：2026-10-19。英雄推荐卡改用腾讯英雄联盟国服官网 CDN 的头像原图，保存到 `web/assets/champions/{ID}.png`，浏览器不再依赖外部 Riot CDN 才能显示头像。

- 官方头像源模板：`https://game.gtimg.cn/images/lol/act/img/champion/{ID}.png`；[阿狸示例原图](https://game.gtimg.cn/images/lol/act/img/champion/Ahri.png)。英雄资料来源仍为[腾讯英雄联盟国服英雄资料](https://lol.qq.com/data/)。
- 取 `web/lol.js` 的 `champions` 与 `web/hextech.js` 的 `hextechHeroes` ID 并集，共 **22 张**：Ahri、Amumu、Annie、Ashe、Brand、Ezreal、Fiora、Garen、JarvanIV、Jinx、LeeSin、Lulu、Lux、Malphite、MissFortune、Nautilus、Orianna、Ornn、Soraka、Thresh、Udyr、Warwick。
- 全部实际解码为 **120 × 120 PNG**，总计 **396,486 字节**（约 387 KiB），没有下载英雄原画或其他大图。每张响应均检查图像 Content-Type、下载上限及实际解码格式／尺寸。
- 腾讯 CDN 的 `Udyr.png` 返回 JPEG 编码数据，已在保持像素尺寸和画面内容不变的情况下重新编码为本地 PNG；其余 21 张保留下载的 PNG 原文件。所有 22 张本地文件均再次经 Pillow 完整解码检查。
