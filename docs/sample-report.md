## 第一部分：召唤师峡谷 · 排位推荐
规则版本：0.3.0；资料编辑日期：2026-10-19
单次游戏时长：30–90 分钟
你对英雄联盟的熟悉程度：常玩：熟悉基础与对局节奏
愿意承担多少操作学习成本：愿意练一些连招与走位
这次最想得到什么体验：稳定练习，准备排位
通常和谁玩：和一位朋友一起
位置有没有明确偏好：只在辅助中推荐英雄
更向往哪种操作体验：保护队友、化解危险
愿意多频繁地关注小地图：能在操作间隙关注地图
距离偏好：优先远程，保留操作距离
排位队列：单 / 双排 · 双人配合
先固定一个位置和两位英雄，在满足当前账号及组队条件后开始排位。
推荐位置：辅助
位置职责：双人对线、视野、保护与开团；保护型和先手型体验差异很大。
需要适应：需要预判队友和敌人的行动，并承担视野与开团判断。
五位置比较：辅助 → 下路 / ADC → 中单 → 上单 → 打野
双人建议：先约定谁负责发起、谁负责跟进或保护；选下路与辅助组合时更容易观察配合。

### 索拉卡（众星之子 / 奶妈）
入门成本较低
以治疗与保护队友为主要反馈，适合享受支援贡献的人。
问卷中你更偏向「团队协作」、「帮助队友发挥」，与这位英雄的玩法标签较接近。
回应了你选择的「保护队友、化解危险」。
符合你优先远程的距离偏好。
操作入门成本在你本次选择的练习范围内。
需要适应：很容易成为对手优先目标，关注队友血量的同时要照顾自己。
1. 先找一个能支援队友又不暴露自己的位置。
2. 观察治疗前后自己的血量与敌方距离。
3. 每局复盘一次被切入，找出可以更早后退的时刻。

### 排位准备路线
1. 建立一个小英雄池：先练首选英雄，再用一位备选应对被禁用、被选走或阵容变化。
2. 用非排位验证手感：固定位置，关注补刀、站位或资源选择，每次只复盘一个问题。
3. 进入单 / 双排 · 双人配合：账号等级、英雄数、段位及组队限制以客户端为准，开始前预留完整对局时间。

#### 大招流 · AP 觉醒 R
玩家常把这一路线叫“大招流”或“双 R 流”：重点是 R 姿态与被动觉醒 R 的范围魔法伤害。乌迪尔没有常规终极技能，不能因此推定所有“终极技能”强化都会触发；先读当前客户端说明。
你的「从容规划、轻松上手」偏好与这条路线较接近。
优先寻找的属性 / 机制：法术强度与魔法穿透；持续技能伤害与范围伤害；进场后生存、移速或技能循环。
没拿到时：没有适配的伤害强化时，保留 R 清线与减速，补生存装备做半肉团战；不为等某一张卡强行投入。
取舍：要接近敌人才能覆盖更多目标；觉醒用在 R 后，就不能同时用觉醒 W / E 自保。避免把“自爆”理解成无条件送出击杀。

#### 穿甲流 · 物理 Q 爆发
以 Q 和觉醒 Q 的近身攻击窗口为中心，考虑攻击力、物理穿透与进场条件；随机到普攻或暴击强化后再决定是否转相应分支。
本次明确偏好未找到足够接近的玩法标签，可将这条路线作为对照体验，先比较操作和风险，再按当局强化调整。
优先寻找的属性 / 机制：攻击力与物理穿透；普攻收益或攻击距离改善；接近目标、保命与撤退能力。
没拿到时：缺乏接近或生存条件时，转半肉 Q 持续战斗；不要为了堆穿甲放弃所有容错。
取舍：依赖能否摸到合适的目标；面对控制与拉扯时纯输出容易阵亡，物理穿透也不直接放大魔法伤害部分。
