# 三角洲行动 · 0.4.0

本次更新以烽火地带为主，兼顾全面战场，回答四个问题：想承担哪种贡献、先试哪位干员、怎样打、先用哪把枪。内容在本地完成后，需要提交推送并通过 Actions，才会进入线上站点。

|---|---|---|
| 兵种 | 突击、信息 / 侦察、工程、支援 / 医疗 | 四方向比较，优先方向与具体打法 |
| 干员 | 17 位 | 同兵种候选、机制摘要、推荐理由、取舍、练习与模式提示 |
| 枪械 | 15 把 | 三把试用候选、距离与手感理由、取舍、靶场练法和原视频 |

枪械库包括 MP7、AS Val、M7、M14、MK47、K437、K416、P90、AKM、M4A1、PKM、RM277、MK4、MDR、汤姆逊。它们是不同手感的比较起点，结果顺序不等于版本强度榜。

## 怎样得到建议

先选模式、PC / 移动端、近 / 中 / 远距离、打法、练习投入和组队方式。打法可选突破、侦察、阵地工程、救援支援、侧翼或自动比较。烽火地带还使用经济、均衡、高投入三种配装取向；它们不是实时价格。

12 题经反向计分后组成六维偏好。干员依据这些偏好、明确打法、距离、学习成本与组队条件排序；手动选择兵种时，在该兵种内比较。低、中、高投入的首试学习成本上限分别为 3、4、5；这个成本是编辑标签。若指定兵种缺少合适的低成本候选，保留比较对象并说明取舍。

枪械先看交战距离，再看操控练习、配装投入和打法。不因“喜欢支援”就认定玩家不能用某种武器，也不把信息位直接等同于远距离狙击。全面战场不使用烽火地带预算或梯度；当期兵种枪池尚未核验，用户应在客户端确认枪械解锁与兵种可用列表。

已有 MBTI 默认是个人备注。三角洲允许主动开启轻量参考，给单个干员最多 ±1.5 分的排序调整；这是编辑假设，不是验证过的人格预测模型，也不会改变枪械、模式或距离资格。英雄联盟仍只作备注。问卷不是标准 MBTI 或已验证心理量表，报告用实际试玩检验喜欢与否。

S11 单枪资料目前覆盖 K437 长枪管、MK4 三连发与全自动、MDR 成型改装、汤姆逊先进枪身的不同弹药环境。其他枪的 S11 梯度保持缺失。M7 的堤风 / 蓝管、MK47 的余烬 / 鏖战 / 普通，以及特殊套件都分别记录，不将上位改装的评价套给基础枪。

这些精选评价的公开页面未逐项明示平台，因此 `platform` 保持 `unspecified`，只展示原视频观点与原条件，**PC 和移动端都不加评级分**。历史档案也不会自动补入 S11。后续若来源明确了平台、模式与基础配装，全部条件匹配的非特殊改装评级才可能得到有限加分；变体不明时继续保留资料而不加分。

已核查范围是原视频公开标题、作者、日期和简介，不代表逐帧看完或当前版本实测。完整原视频与各条条件见 [枪械来源](delta-weapon-sources.md)；机制来源见 [干员来源](delta-operator-sources.md)，美术见 [图片来源](delta-visual-sources.md)。

## 下一赛季怎样更新

三类资料独立存放，扩充来源无需重新改页面结构：

| 文件 | 维护内容 |
|---|---|
| `web/delta.js` | 专用题、实际条件、推荐规则、导出 |
| `web/delta-operators.js` | 兵种、干员事实、编辑标签和练习 |
| `web/delta-weapons.js` | 枪械候选、赛季元数据、作者观点与适用范围 |
| `web/delta-visuals.js` | 背景、题图、头像与官方来源 |
| `docs/delta-weapon-sources.md` | 逐条来源、核查边界和更新记录 |

新增赛季时：

1. 在 `weaponSources` 添加本人原视频的标题、URL、作者与发布日期，在 `weaponSeasons` 添加唯一 `id`、名称、模式、平台、来源、编辑核查日期和说明。当前“最近收录”取数组第一项，按新到旧维护。
2. 为核验过的枪械增加 `seasonRatings`。同时记录 `seasonId`、`tier`、`variant`、`mode`、`platform`、`scope`、`source`、`date`、`notes` 和原观点标签。没查到的梯度保留缺失，未知端用 `unspecified`；预测榜与正式榜分开。
3. 先核对模式，再核对平台、枪管 / 套件、弹药与原视频日期。不跨赛季补分，不把手游单列条目用于 PC，不自动选最高变体。热更新用新日期和新来源，旧记录保留为历史。
4. 取得全面战场当期兵种枪池后，另外记录来源与版本，再增加已核验可用范围；不能只按枪械名称或类型猜测。
5. 运行 `npm test`，在本地完成两种模式的报告和手机布局检查，然后提交、推送。发布状态查看 [GitHub Actions](https://github.com/KaynJ/main-lab/actions)，部署步骤见 [部署说明](deployment.md)。

当前没有自动抓榜、实时交易行或账号解锁接口。后续优先补平台明确的来源、实际可用枪池，以及玩家试玩后的喜欢程度、压力和继续尝试意愿。
